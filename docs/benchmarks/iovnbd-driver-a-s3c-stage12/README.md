# Stage 12 — deployable-model IO-VNBD evaluation

This directory contains the submission evidence generated by the current `shared/models/velocity_cnn.onnx` model. The dataset is the recording-disjoint IO-VNBD Driver A S3c evaluation recording; calibration uses only samples before 300 s and the GNSS blackout begins at 1,200.1 s.

## Reproduce

From the repository root, download the public phone/vehicle pair and run:

```powershell
py -3.13 ml/scripts/fetch_iovnbd_subset.py --recording driver-a-s3c
$env:PYTHONPATH = "ml/src;edge/python/src"
py -3.13 ml/scripts/stage12_evaluate.py
```

The replay starts from the final GNSS-aided speed and course at loss. During the blackout, only timestamps and vehicle-frame IMU features reach the velocity model and inertial integrator; ground-truth position, speed, heading, and yaw-rate labels are excluded until scoring.

| Method | Distance | Endpoint error | Drift | Update rate |
| --- | ---: | ---: | ---: | ---: |
| Forward-acceleration INS | 1,867.62 m | 96.34 m | 5.16% | 10 Hz |
| AI-assisted GNSS-anchored INS | 1,867.62 m | 94.88 m | **5.08%** | 10 Hz |

The AI-assisted result is below the SIH 10% offline benchmark ceiling. The result is an offline replay, not a claim of fixed-mount real-road performance.
