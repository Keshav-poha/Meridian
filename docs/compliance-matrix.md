# SIH 26168 compliance matrix

This matrix maps the requested capabilities to evidence in the repository. “Partial” is deliberate: it means the code exists only offline, only for the velocity sub-system, or still lacks required field validation.

| Problem-statement requirement | What was built | Proof / status |
| --- | --- | --- |
| Ingest IMU, GNSS, and ground truth from IO-VNBD | Timestamp-aligned IO-VNBD loader with 10 Hz interpolation, source-gap rejection, and a tracked Driver A S3c held-out replay. | [`ml/src/idr_ml/iovnbd.py`](../ml/src/idr_ml/iovnbd.py), [`ml/scripts/stage2_ingest.py`](../ml/scripts/stage2_ingest.py), ML tests. **Complete offline.** |
| Calibrate phone mounting pitch, roll, yaw & mount independence | Static gravity leveling provides immediate pitch/roll resolution; vertical angular rate projection ($\vec{\omega} \cdot \hat{g}$) is mathematically invariant to horizontal mount yaw, removing the rigid 20-turn requirement. | [`mobile/lib/services/imu_preprocessor.dart`](../mobile/lib/services/imu_preprocessor.dart), [`ml/src/idr_ml/calibration.py`](../ml/src/idr_ml/calibration.py). **Complete.** |
| Denoise IMU and reject idle, bumps, mount shake, non-navigation motion | Gravity removal, vehicle-frame transform, stationary/ZUPT, shock cooldown, and freshness gates. Stationary rest triggers Zero-Velocity Updates (ZUPT). | [`mobile/lib/services/motion_gate.dart`](../mobile/lib/services/motion_gate.dart). **Implemented.** |
| Estimate vehicle forward velocity without OBD-II | 961-parameter TinyVelocityCNN regresses scalar forward speed from 2-second IMU windows; supports standalone propagation without requiring a prior GNSS anchor. | [`ml/src/idr_ml/velocity_model.py`](../ml/src/idr_ml/velocity_model.py), [`mobile/lib/services/ins_speed_filter.dart`](../mobile/lib/services/ins_speed_filter.dart). **Complete.** |
| Integrate velocity and heading using car non-holonomic constraints | Forward-only NHC integrator resets lateral/vertical velocity and integrates mount-independent vertical yaw rate. | [`ml/src/idr_ml/dead_reckoning.py`](../ml/src/idr_ml/dead_reckoning.py), [`mobile/lib/services/live_idr_engine.dart`](../mobile/lib/services/live_idr_engine.dart). **Complete.** |
| Map-match DR to OpenStreetMap roads | Mobile runtime caches nearby OSM road geometry while GNSS is available and constrains DR only when distance, ambiguity, and heading gates pass; unsafe candidates retain the raw prediction. GNSS positions are never snapped. The HMM/Viterbi matcher remains available for offline evaluation. | [`mobile/lib/services/road_constrained_matcher.dart`](../mobile/lib/services/road_constrained_matcher.dart), [`ml/src/idr_ml/map_matching.py`](../ml/src/idr_ml/map_matching.py), [`docs/safety/map-matching.md`](safety/map-matching.md). **Implemented on mobile with a local segment matcher; edge and causal HMM integration remain partial.** |
| Fuse GNSS and INS | The mobile runtime uses Flutter's navigation stream with supplemental native GPS observations, mount-independent dead reckoning, and smooth reacquisition. Supports cold start with GNSS disabled. | [`ml/src/idr_ml/fusion.py`](../ml/src/idr_ml/fusion.py), [`mobile/lib/services/live_idr_engine.dart`](../mobile/lib/services/live_idr_engine.dart). **Implemented; EKF/UKF pending.** |
| Switch GNSS-aided INS ↔ DR without a visible jump | Mobile has GNSS-aided, DR, and 500 ms reacquisition states; operates continuously even when GNSS is disabled from app launch. | [`mobile/lib/services/live_idr_engine.dart`](../mobile/lib/services/live_idr_engine.dart), [`ml/src/idr_ml/mode_switch.py`](../ml/src/idr_ml/mode_switch.py). **Implemented.** |
| Export for mobile and edge | Hash-bound TFLite and ONNX velocity exports, shared normalization, TFLite mobile loader, and the verified Python ONNX Runtime reference. | [`shared/models/`](../shared/models), [`ml/scripts/stage10_export.py`](../ml/scripts/stage10_export.py), [`edge/python`](../edge/python). **Complete for velocity:** `edge/cpp` is an uncompiled integration interface seam; full edge navigation remains partial. |
| Mobile update rate 10 Hz; edge around 200 Hz | Mobile ticker is configured at 100 ms. The verified Python ONNX Runtime reference resamples a 200 Hz input stream and profiled at about 2,763 velocity inferences/s. `edge/cpp` has not been compiled as a FOG-grade navigation pipeline. | [`mobile/lib/services/live_idr_engine.dart`](../mobile/lib/services/live_idr_engine.dart), [`edge/python`](../edge/python), [`docs/test-results.md`](test-results.md). **Partial:** physical mobile rate and complete 200 Hz edge navigation rate are not measured. |
| DR drift below 10% during GNSS blackout | Held-out 59.9-second IO-VNBD Driver A S3c replay ends at 94.88 m error over 1,867.62 m: 5.08%. | [`docs/benchmarks/iovnbd-driver-a-s3c-stage12/`](benchmarks/iovnbd-driver-a-s3c-stage12/). **Passes one offline split; real-drive validation pending.** |
| IO-VNBD subset plots and metrics | Versioned position, speed-tracking, and drift-versus-distance SVGs plus CSV/JSON metrics and sample trajectory are tracked. | [`position_plot.svg`](benchmarks/iovnbd-driver-a-s3c-stage12/position_plot.svg), [`speed_tracking_plot.svg`](benchmarks/iovnbd-driver-a-s3c-stage12/speed_tracking_plot.svg), [`drift_vs_distance_plot.svg`](benchmarks/iovnbd-driver-a-s3c-stage12/drift_vs_distance_plot.svg). **Complete offline.** |
| Navigation and validation UI | Flutter splash, map, route controls, GPS-lost state, Developer Mode, confidence display, and trip logging. | [`mobile/lib/ui/meridian_shell.dart`](../mobile/lib/ui/meridian_shell.dart), [`mobile/lib/services/trip_recorder.dart`](../mobile/lib/services/trip_recorder.dart). **Core UI complete; real road validation pending.** |
